# Blog académico: Jeep y marketing digital

Sitio estático listo para GitHub Pages.

## Archivos
- `index.html`: contenido del blog en español.
- `styles.css`: diseño responsive con verde militar, arena y negro.
- `script.js`: navegación suave.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube estos tres archivos a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub publicará el sitio y mostrará su dirección.

Las imágenes se cargan desde Unsplash y las tipografías desde Google Fonts; se necesita conexión a internet para mostrarlas.
